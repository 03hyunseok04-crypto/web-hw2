## 어려웠던 점 3가지와 해결
어려웠던 점: 영화 정보를 배열과 객체에 어떻게 넣어야 하는지 헷갈렸다.

해결: 예시 코드를 참고해서 영화 제목, 평점, 개봉일 등을 정리했다.


어려웠던 점: 평점이 높은 순서대로 정렬하고 원하는 영화를 검색하는 것이 어려웠다.

해결: sort()와 filter()를 사용해서 해결했다.


어려웠던 점: TMDB에서 가져온 데이터가 많아서 필요한 정보를 찾기 어려웠다.

해결: 함수를 사용해서 영화 목록을 가져오고 평점을 계산했다
